# Prompts

Prompts are generated from blueprints, capability modules, domain knowledge rules, and tool specs.

Use [[../_templates/Prompt Template|Prompt Template]].

## Rules

- Keep stable behavior separate from replaceable domain content.
- Make tool-use rules explicit.
- Include refusal and uncertainty behavior.
- Link every prompt to evals.
- Do not let prompts become the only source of system truth.
