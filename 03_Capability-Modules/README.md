# Capability Modules

Capability modules are reusable behaviors that can be attached to many agents.

Use [[../_templates/Capability Module Template|Capability Module Template]].

## Examples

- Diagnostic interview
- Evidence grounding
- Retrieval planning
- Critique and red-team review
- Structured decision memo
- Tool-use policy
- Escalation and refusal handling
