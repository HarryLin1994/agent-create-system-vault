# Concept - Evidence Hierarchy

## One-line Summary

Agents should rank evidence by provenance and relevance before converting it into advice.

## Useful Hierarchy

- Direct user-provided facts about the current situation.
- Primary sources or direct operator accounts.
- Multiple independent sources that agree.
- Domain-specific case studies with clear context.
- Expert opinion with stated assumptions.
- Generic advice, slogans, or unsupported claims.

## Agent Usage

Use this concept when the agent must decide whether it has enough support to make a recommendation.

## Limitations

High-quality evidence can still be misleading if the context differs from the user's situation.
