# Sources

Create one source note per book, article, report, interview, or internal document.

Use [[../../_templates/Knowledge Source Template|Knowledge Source Template]].

## Source Quality Guide

- `high`: primary source, direct operator writing, audited report, or multiple corroborating sources.
- `medium`: credible book, long-form profile, expert analysis, or well-sourced presentation.
- `low`: unsourced claim, anecdote, second-hand summary, or unclear provenance.
