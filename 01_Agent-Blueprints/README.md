# Agent Blueprints

An agent blueprint defines one agent as a product: its user, job, domain boundary, behavior, tools, knowledge, and tests.

Use [[../_templates/Agent Blueprint Template|Agent Blueprint Template]].

## Required Sections

- User and job-to-be-done
- Scope and non-goals
- Capabilities
- Knowledge dependencies
- Tool dependencies
- Output style
- Failure modes
- Eval set
