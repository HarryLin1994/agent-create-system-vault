# Expert Skill Factory v1 Pipeline

## One-line Summary

This overview shows how a business need becomes a reusable expert skill module with domain retrieval, a skill draft, tests, and registry tracking.

## Diagram Files

- HTML: [Expert Skill Factory v1 Pipeline.html](Expert%20Skill%20Factory%20v1%20Pipeline.html)
- Source JSON: [Expert Skill Factory v1 Pipeline.workflow.json](Expert%20Skill%20Factory%20v1%20Pipeline.workflow.json)

## Main Flow

Business need -> skill contract -> knowledge need -> knowledge map -> retrieval index -> context pack -> `SKILL.md` draft -> tests -> registry.

This is the top-level map. The detailed retrieval work is handled by [[Domain Knowledge Retrieval v1 Pipeline]].
